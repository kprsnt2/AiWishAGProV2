# Nexus

A fully functional, locally-hosted "Second Brain" Knowledge Management System built with Vanilla JS, IndexedDB, and HTML5 Canvas.

## Features
1. **Persistent Local Database**: Uses IndexedDB to store all your notes locally and instantly within your browser. No data ever leaves your computer.
2. **Real-time Markdown Editor**: A dual-pane editor that renders Markdown instantly.
3. **Bidirectional Linking**: Type `[[Name of Note]]` anywhere in your text to create a link. A "Linked Mentions" (backlinks) section is automatically generated at the bottom of the target note.
4. **Interactive Knowledge Graph**: A custom physics-engine built using Canvas. When you click "Graph View", it simulates spring forces and repulsion to map out exactly how all your thoughts connect.

## How to Run
No Node backend or server is required. 
1. Clone the repository.
2. Open `index.html` in your web browser.
3. Start typing, creating notes, and building your knowledge graph!
